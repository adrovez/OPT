# 🎯 Branding & Design System — OPT

## 1. 📌 Descripción del Producto
**Nombre:** OPT  
**Tipo:** Aplicación web de gestión para ópticas  
**Propuesta de valor:** Centralizar toda la operación de una óptica en una sola plataforma.

### Funcionalidades principales:
- Gestión de clientes
- Agenda de citas
- Atención clínica
- Órdenes de trabajo
- Productos y stock
- Pagos
- Reportería

---

## 2. 🧠 Concepto de Marca

### Personalidad:
- Profesional
- Tecnológica
- Clara
- Confiable
- Moderna

### Idea central:
> "Control total y claridad en la gestión óptica"

### Naming:
**OPT** → Relacionado con:
- Visión (óptica)
- Precisión
- Claridad
- Orden

---

## 3. 🧿 Logo

### Concepto:
- Un **ojo estilizado** que representa visión
- Integración con la letra **“E”**
- Forma simple, moderna y escalable

### Variantes:
- Logo horizontal (principal)
- Isotipo (solo ojo + E)
- Icono app (fondo oscuro + símbolo)

### Uso:
- Preferir fondos claros
- Versión blanca sobre fondo oscuro
- Mantener espacio de seguridad (mínimo 1x altura del logo)

---

## 4. 🎨 Paleta de Colores

### Primarios:
- Azul oscuro: `#0D1B3D` → Confianza, profesionalismo
- Azul medio: `#2563EB` → Tecnología, acción

### Secundarios:
- Celeste: `#06B6D4` → Frescura, salud
- Verde: `#10B981` → Éxito, confirmación

### Neutros:
- Gris claro: `#F3F6FA`
- Blanco: `#FFFFFF`

### Uso:
- Azul oscuro → headers, sidebar
- Azul medio → botones principales
- Verde → estados positivos
- Celeste → elementos informativos

---

## 5. 🔤 Tipografía

### Principal:
- **Poppins**

### Características:
- Moderna
- Alta legibilidad
- Ideal para UI

### Jerarquía:
- H1: Bold
- H2: SemiBold
- Body: Regular
- Labels: Medium

## 6. 🧩 UI / UX Guidelines

### Estilo general:
- Minimalista
- Limpio
- Espaciado amplio
- Uso de cards

### Componentes clave:

#### Sidebar:
- Fondo azul oscuro
- Iconos + texto
- Estado activo destacado

#### Dashboard:
- Tarjetas con métricas:
  - Citas
  - Atenciones
  - Ventas
- Gráficos simples

#### Formularios:
- Inputs redondeados
- Labels claros
- Validaciones visuales

#### Tablas:
- Limpias
- Con estados (pendiente, completado, etc.)

- Recepcionista

### Objetivo:
> Reducir tiempo operativo y errores manuales

---

## 12. 🚀 Instrucciones para IA Diseñadora

Diseñar interfaz basada en:

- Estilo moderno tipo SaaS
- Sidebar izquierda + contenido principal
- Uso de cards y dashboards
- Colores definidos en paleta
- Tipografía Poppins
- Iconos outline
- Experiencia limpia tipo:
  - Stripe
  - Notion
  - Linear

### Prioridades:
1. Facilidad de uso
2. Rapidez
3. Visualización de datos
4. Flujo lógico de trabajo
