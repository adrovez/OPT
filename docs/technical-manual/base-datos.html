Base de datos: dbOPT 31 tablas Scripts 000–033 Soft-delete universal Multi-tenant GUID

Resumen general

La base de datos dbOPT corre en SQL Server 2022 (compatible Azure SQL). El esquema se gestiona con scripts numerados en src/basedatos/ — no se usa EF Core Migrations.

Regla multi-tenant: Todas las tablas de negocio tienen columna TenantId. Nunca consultar sin filtrar por TenantId — un error aquí expone datos de otros clientes.
PKs: Tablas de negocio → UNIQUEIDENTIFIER DEFAULT NEWSEQUENTIALID(). Catálogos compartidos → INT IDENTITY. Nunca usar NEWID() como DEFAULT (fragmenta índice clustered).

Guía: Agregar un Nuevo Script

Pasos para agregar cambios de esquema. Próximo número disponible: 034_.

-- Nombrar: 034_descripcion.sql
-- Siempre: USE [dbOPT]; GO

-- Para tablas nuevas: verificar existencia antes de crear
IF OBJECT_ID('[dbo].[OPT_NuevaTabla]', 'U') IS NULL
BEGIN
    CREATE TABLE [dbo].[OPT_NuevaTabla]
    (
        [NuevaTablaId] UNIQUEIDENTIFIER NOT NULL DEFAULT NEWSEQUENTIALID(),
        [TenantId]     UNIQUEIDENTIFIER NOT NULL,
        -- ... columnas de negocio ...
        [CreatedAt]    DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME(),
        [UpdatedAt]    DATETIME2 NULL,
        [CreatedBy]    NVARCHAR(100) NULL,
        [UpdatedBy]    NVARCHAR(100) NULL,
        [IsDeleted]    BIT NOT NULL DEFAULT 0,

        CONSTRAINT PK_OPT_NuevaTabla PRIMARY KEY CLUSTERED ([NuevaTablaId]),
        CONSTRAINT FK_OPT_NuevaTabla_Tenant
            FOREIGN KEY ([TenantId]) REFERENCES [dbo].[OPT_Tenant] ([TenantId])
    );
END
GO

-- Para ALTER TABLE (incremental): verificar columna antes de agregar
IF NOT EXISTS (
    SELECT 1 FROM sys.columns
    WHERE object_id = OBJECT_ID('OPT_TablaExistente')
    AND name = 'NuevoCampo'
)
BEGIN
    ALTER TABLE [dbo].[OPT_TablaExistente]
    ADD [NuevoCampo] NVARCHAR(100) NULL;
END
GO
Buenas prácticas: Usar SYSUTCDATETIME() para timestamps. PKs de negocio siempre UNIQUEIDENTIFIER DEFAULT NEWSEQUENTIALID(). Catálogos compartidos con INT IDENTITY. Índices filtrados con WHERE IsDeleted = 0. Datos semilla con guards IF NOT EXISTS.
Nunca: Usar NEWID() como DEFAULT (fragmenta el índice clustered). Nunca modificar scripts ya ejecutados en producción. Nunca hacer DELETE físico de datos OPT_ — usar soft delete (IsDeleted = 1).
