# User Manual

Documentation for end users of the OPT application.

## Structure

```
docs/user-manual/
├── README.md              # This file
├── getting-started.md     # First-time user guide
├── workflows/             # Task-specific guides
│   └── example-workflow.md
└── faq.md                 # Frequently asked questions
```

## Writing Guidelines

- Write for non-technical users
- Use step-by-step numbered instructions
- Include screenshots for each step
- Use clear, simple language
- Avoid technical jargon or explain it when necessary

## Template for New Guides

```markdown
# [Feature Name]

## What This Does
[Brief description in plain language]

## Prerequisites
- [Required setup or permissions]

## Steps
1. [Step one with screenshot reference]
2. [Step two with screenshot reference]
3. ...

## Troubleshooting
- **Problem**: [Common issue]
  **Solution**: [How to fix]
```
